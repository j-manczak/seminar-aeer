## 4. Regression Specification Consistency

### 4.1 Specification in APPENDIX_STRUCTURE.md Section C.1

```
Y_{ist} = β₀ + β₁ POST_t + β₂ DOWNSTREAM_i + β₃ (POST_t × DOWNSTREAM_i) 
          + Σ_m δ_m MONTH_m + ε_{ist}
```

**Interpretation:** Station-panel model with 3 main effects (POST, DOWNSTREAM, interaction) + month dummies.

### 4.2 Specification in seminar-aeer/chapters_4_5_6.md Section 5.1

```
Δ_t = α + β · 1(t > 2011-08-06) + Σ_{m=1}^{11} γ_m 1(month_t = m) + ε_t
```

**Interpretation:** Paired daily difference (NOT a panel model) where Δ_t = downstream − upstream.

### 4.3 What the Code Actually Implements

**In `src/did_analysis.py`:**
```python
model = ols('outcome ~ C(month) + post + downstream + post:downstream', 
            data=long_format_did_data).fit()
```

**Interpretation:** This matches C.1 (station-panel model), NOT C.2 (paired difference).

### 4.4 Critical Issue: Two Specifications, One Implementation

- **C.2 (thesis) uses PAIRED DIFFERENCES** — removes confounders at river-basin scale by subtracting upstream from downstream
- **C.1 (APPENDIX) & actual code use STATION-PANEL** — relies on downstream/upstream indicator and interaction term
- **R² gap:** Paired difference typically has R²≈0.48 (from earlier daily-frequency analysis referenced in session notes); panel model has R²≈0.94–0.97 (what's in results)

**Issue:** The two specs are NOT equivalent. The choice of specification affects inference.

**Verdict:** 🔴 **CRITICAL INCONSISTENCY** — Documentation describes paired-difference (C.2), APPENDIX/code implements station-panel (C.1). They give different results.

### 4.5 Root Cause

The thesis (`seminar-aeer/chapters_4_5_6.md`) was written for a **daily-frequency paired-difference analysis**. The current code implements a **monthly-aggregated station-panel model**. These are two different empirical strategies. The APPENDIX C.1 formulation matches what the code does, but the thesis Section 5.1 does not.

### 6.1 Daily-frequency analysis (earlier version)

### 6.2 Monthly-panel analysis (current code)

- Result: **Positive effect (warming)**, β ≈ +0.86°C, p = 0.241

### 6.3 Root Cause Analysis

**Hypothesis:** Sample imbalance due to Lauffen's late start.

**Evidence:**
- Lauffen begins: 2010-03-16
- Nominal pre-period (if April 30 cutoff): 2006-04 to 2011-04 → Only ~13 months with data (2010-03 to 2011-04)
- Post-period: ~60 months with data (2011-04 to 2016-04)
- **Imbalance ratio:** 13:60 or ~22% pre vs. 78% post

**Effect:** The pre-period is dominated by a single year (2010–2011), which may not be representative of the true long-run baseline. The upstream-downstream gap could have changed (exogenously or due to measurement differences) in that single year, leading to a false sign flip.

**Verdict:** 🟡 **LIKELY EXPLANATION** — Lauffen's data sparsity creates severe pre-period imbalance, likely explaining sign flip. This should be flagged in limitations.
